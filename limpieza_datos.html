Proyecto de Python para Gestión de Datos Sociales
Volver al Portafolio

Descripción General

Colección de notebooks de Jupyter diseñados para automatizar la limpieza, validación y análisis de bases de datos de beneficiarios. El proyecto aborda problemas comunes como duplicados exactos y difusos, muestreo estadístico y generación de reportes.

Notebooks y Funcionalidades

1. Detección de Duplicados e Inconsistencias (duplicado_inco.ipynb)

Identifica duplicados por ID y detecta discrepancias en datos clave como nombres y fechas. Normaliza texto para reducir falsos positivos.

2. Duplicidad Inversa y Fuzzy Matching (duplicidad_inversa.ipynb)

Detecta personas con diferentes IDs pero nombres similares (fuzzy matching ≥80%) o idénticos. Utiliza técnicas de bloqueo para optimizar el rendimiento.

3. Generación de Reportes (gors.ipynb)

Automatiza la creación de indicadores agrupados por Oficina, Sexo y Status, separando resultados según criterios de emergencia.

4. Separación de Duplicados (l.duplicados.ipynb)

Separa el dataset en archivos de registros únicos y duplicados basándose en dos columnas clave.

5. Muestreo Estadístico (muestra_simple.ipynb)

Calcula y extrae una muestra aleatoria representativa usando la fórmula de Cochran (95% confianza) aplicada a poblaciones filtradas por servicio y fecha.

Tecnologías Utilizadas

  • Python 3.x
  • Pandas (Manipulación de datos)
  • Openpyxl (Lectura/Escritura Excel)
  • Fuzzywuzzy (Comparación difusa de cadenas)
